How to use TreePots 📖

Get your first Minecraft bot running.

1️⃣

Create your bot

Open Create Bot and enter the Minecraft username, server IP, port and version.

2️⃣

Start the bot

Open My Bots and press Start to connect your bot.

3️⃣

Use Console

Monitor logs and communicate with the bot from the Console.

4️⃣

Automation

Create automated rules for messages and approved actions.

5️⃣

Upgrade

After the trial, activate a paid plan using a TreePots code.

6️⃣

Delete Bot

Delete bots you no longer need using the Delete button.
