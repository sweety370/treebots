How to use TreePots 📖

Get your first Minecraft bot running.

1️⃣

Create your bot

Open Create Bot and enter the Minecraft username, server IP, port and version.

2️⃣

Start the bot

Open My Bots and press Start to change the bot status.

3️⃣

Use Console

Monitor the selected bot from the console.

4️⃣

Automation

Create automated rules for your bots.

5️⃣

Upgrade

Activate a paid plan using a TreePots code.

6️⃣

Delete Bot

Delete bots you no longer need.
