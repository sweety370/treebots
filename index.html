How to use TreeBots 📖

Get your first bot running.

1️⃣

Create your bot

Open Create Bot and enter the Minecraft username, server IP, port and version.

2️⃣

Start the bot

Open My Bots and press Start to update the bot status through the API.

3️⃣

Use Console

Open the console to monitor your selected bot.

4️⃣

Automation

Create automated rules for approved actions.

5️⃣

Upgrade

Upgrade your TreeBots plan when paid-plan validation is connected.

6️⃣

Delete Bot

Delete bots directly from your D1 database using the Delete button.
